    Read `.github/workflows/ci.yml` in full first. The existing job is named `ci`. The file uses `actions/checkout@v4`, `actions/setup-java@v4`, and `actions/setup-node@v4` — use the same versions for the new job.

    Append an `e2e` job to the `jobs:` block (after the existing `ci` job, as a sibling job). The `e2e` job must NOT be nested inside the `ci` job.

    The `e2e` job spec:

    Name: `E2E Tests (Playwright)`
    `runs-on: ubuntu-latest`
    `needs: ci` — this ensures E2E only runs after the existing ci job passes (backend tests + frontend build)

    Services block (PostgreSQL):
    ```
    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_DB: booktracker_e2e
          POSTGRES_USER: bt_e2e
          POSTGRES_PASSWORD: bt_e2e_pw
        options: >-
          --health-cmd "pg_isready -U bt_e2e -d booktracker_e2e"
          --health-interval 5s
          --health-timeout 5s
          --health-retries 10
        ports:
          - 5432:5432
    ```

    Steps in order:
    1. `uses: actions/checkout@v4` — name: Checkout
    2. Set up JDK 21 with `actions/setup-java@v4`, `java-version: "21"`, `distribution: "temurin"`, `cache: maven`
    3. Build fat jar: `run: mvn -DskipTests package -B -q` — name: "Build fat JAR (skip tests — verified in ci job)"
    4. Set up Node 20 with `actions/setup-node@v4`, `node-version: "20"`, `cache: npm`, `cache-dependency-path: e2e/package-lock.json`
    5. Install E2E dependencies: `working-directory: e2e`, `run: npm ci` — name: "Install E2E dependencies"
    6. Install Playwright Chromium: `working-directory: e2e`, `run: npx playwright install --with-deps chromium` — name: "Install Playwright Chromium"
    7. Run Playwright E2E suite:
       - `working-directory: e2e`
       - `run: npx playwright test --project=chromium`
       - `name: "Run Playwright E2E suite"`
       - `env` block with:
         - `CI: "true"`
         - `E2E_DB_URL: jdbc:postgresql://localhost:5432/booktracker_e2e`
         - `E2E_DB_USER: bt_e2e`
         - `E2E_DB_PASS: bt_e2e_pw`
         - `E2E_JWT_SECRET: ${{ secrets.E2E_JWT_SECRET }}` — never hardcoded, always a secret
    8. Upload Playwright report:
       - `uses: actions/upload-artifact@v4`
       - `name: "Upload Playwright report"`
       - `if: ${{ !cancelled() }}` — upload even when tests fail, not just on success
       - `with.name: playwright-report`
       - `with.path: e2e/playwright-report/`
       - `with.retention-days: 7`

    Add an inline comment on step 3 explaining why tests are skipped: "Backend tests already verified in the ci job — skipping here to save CI minutes."
    Add an inline comment on the E2E_JWT_SECRET env var: "Must be a test-only JWT secret — never the production JWT_SECRET."

    Use the `Edit` tool to append the e2e job to the YAML. Do not overwrite the existing ci job or the file header.
  </action>
