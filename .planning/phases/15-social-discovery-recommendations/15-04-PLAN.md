**Step A — DiscoverySection.tsx:**

Create `frontend/src/components/social/DiscoverySection.tsx`. This is a generic section wrapper for horizontal book card rows.

Props: `{ title: string; children: React.ReactNode; subtitle?: string }`

Render:
```
<section className="mb-6">
  <h2 className="text-base font-semibold mb-1">{title}</h2>
  {subtitle && <p className="text-xs text-muted-foreground mb-2">{subtitle}</p>}
  <div className="flex gap-3 overflow-x-auto pb-2 -mx-4 px-4 scrollbar-none snap-x snap-mandatory">
    {children}
  </div>
</section>
```

The `-mx-4 px-4` bleed ensures the scroll row is flush with the screen edge without causing page-level horizontal overflow. This guards against Pitfall 2 from RESEARCH (horizontal page scroll on mobile). `scrollbar-none` hides the scrollbar on desktop. `snap-x snap-mandatory` enables iOS Safari momentum scrolling with snap points.

Export as a named export: `export function DiscoverySection`.

**Step B — DiscoveryBookCard.tsx:**

Create `frontend/src/components/social/DiscoveryBookCard.tsx`.

Props: `{ title: string; coverId: string | null; olKey: string }`

Import `Link` from `react-router-dom` and `BookCoverImage` from `../../components/shared/BookCoverImage`.

Render:
```
<Link
  to={`/books/${olKey}`}
  className="flex-shrink-0 w-24 snap-start"
  aria-label={title}
>
  <BookCoverImage
    key={coverId ?? olKey}
    coverId={coverId}
    title={title}
    className="aspect-[2/3] w-24 object-cover rounded-md"
  />
  <p className="text-xs text-muted-foreground mt-1 line-clamp-2">{title}</p>
</Link>
```

`key={coverId ?? olKey}` on `BookCoverImage` is mandatory — Pitfall 3 from RESEARCH (component reuse across different books without remounting). The `key` prop must be on `BookCoverImage`, not on the outer `Link`.

`snap-start` on the Link ensures each card snaps to position in the `snap-x` container.

The minimum touch target is provided by the full `w-24` (96px wide) link wrapping both the cover and title.

Export as a named export: `export function DiscoveryBookCard`.
